- project overview and responsibilities
- project screenshots
- a button to open the complete PDF report
- a button to download the PDF report

Keep the assets folder beside index.html when uploading the site to Replit or another host.

To run it in Replit, keep index.html, styles.css, server.py, and the assets folder in the
project root, then set the Run command to:

python3 server.py
